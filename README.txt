CAREPOINT HOSPITAL MANAGEMENT SYSTEM — INTERACTIVE PROTOTYPE

HOW TO USE
1. Download and extract carepoint_hospital_prototype.zip.
2. Open the extracted folder.
3. Double-click index.html to open it in Chrome, Edge, Firefox, or another modern browser.
4. Use the left navigation to explore six pages:
   - Dashboard
   - Appointments
   - Doctors
   - Departments
   - Book a Visit
   - My Profile

INTERACTIONS
- Navigate between six pages/modules.
- Book appointment requests and see them appear in the appointment list and dashboard.
- Search doctor names and specialties from the top search box.
- Jump from doctor cards or department cards to the booking form.
- Update the sample patient profile.
- Cancel a newly added appointment request in the appointment table.

IMPORTANT
This is a front-end academic prototype. It does not connect to a backend or hospital database, does not transmit form details, and does not provide real medical or emergency services. Some preloaded appointment records are illustrative sample data.
